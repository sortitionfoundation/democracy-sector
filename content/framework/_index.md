We present a framework of standards for deliberative decision making.

Each standard is set out across three tiers, representing increasing depth of practice: **Core**, **Desirable** and **Stretch**.

- **Core** is the floor: the non-negotiable minimum for a process to legitimately call itself deliberative engagement. If Core isn't met, the work may still be valuable, but it shouldn't be described as deliberative engagement as this framework defines it.
- **Desirable** builds from there where resources and context allow.
- **Stretch** articulates what deeper power-sharing and sustaining deliberative practice looks like in context.

The same standards can also be useful for community-led or self-governed deliberation, though not every criterion applies - several Desirable and Stretch criteria assume resource or infrastructure that community-led processes won't always have.

Practitioners can use it to articulate design intentions; commissioners to set specifications and create accountability; evaluators to assess what happened against what was planned and for the public to assess integrity in deliberative engagement. We are developing an interactive tool that guides users through the standards, to be developed for engagement, accessibility and design once comments have been integrated on the whole framework.
