The deliberative standards are a co-created framework for deliberative public engagement in decision making.

Each standard is set out across three tiers, representing increasing depth of practice: **Core**, **Desirable** and **Stretch**.

- **Core** is the floor: the non-negotiable minimum for a process to legitimately call itself deliberative engagement. If Core is not met, the work may still be valuable, but it should not be described as deliberative engagement as this framework defines it.
- **Desirable** builds from there where resources and context allow.
- **Stretch** sets out what deeper power-sharing and sustaining deliberative practice looks like in context.

The same standards can also be useful for community-led or self-governed deliberation, although not every criterion will apply - several Desirable and Stretch criteria assume resource or infrastructure that community-led processes may not have.

The standards can be used by:

- Practitioners to articulate design intentions
- Commissioners to set specifications and create accountability
- Evaluators to assess what happened against what was planned, and the public to assess the integrity of deliberative engagement.
